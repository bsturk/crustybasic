# crustyBASIC on ZX81 and Timex Sinclair 1000

Use `@OPTION TARGET zx81` for the PAL ZX81 profile. Use
`@OPTION SYSTEM zx81.timex_sinclair` for the NTSC Timex Sinclair 1000.

Both systems build an autostarting `.p` program for a machine with 16K RAM.
Portable runtime calls are documented in [`../API.md`](../API.md).

## Systems

| System | Video | Output |
| --- | --- | --- |
| `zx81.orig` | PAL, 50 Hz | `.p` |
| `zx81.timex_sinclair` | NTSC, 60 Hz | `.p` |

## Basics

| Item | Value |
| --- | --- |
| CPU | Zilog Z80 |
| Required RAM | 16K |
| Text | 32x24 |
| Block graphics | 64x44 |
| Code start | `$43AB` |
| Program RAM top | `$8000` |
| `REAL` | Sinclair 5 byte format using the ROM calculator |
| Sound | Not available on a stock machine |

Build a program with a `vasmz80_oldstyle` executable available through the
normal assembler search path:

```bash
crustybasic build hello.cbs -o hello.p
```

## Text and cells

The `.p` wrapper creates a full 32x24 display file, and `TEXT_HEIGHT` exposes
all 24 rows. The ROM may use rows 22 and 23 for input and reports, so programs
that need those displays can reserve the rows themselves. `CLS` clears all 24
rows.

Text is converted to ZX81 display codes as it is printed. `#` prints as a
solid block and unsupported characters are shown as `?`. Brace escapes such as
`{$81}` place the block and inverse glyphs directly. Printing past the final
row stays on that row.

Pure crustyBASIC and the `zx81_basic` dialect both support `SCROLL`. It moves
the display up one row, clears the final row, and puts the `PRINT` position at
the beginning of that row. Scrolling is explicit rather than automatic.

## Input

`KEY`, `INKEY`, `RAWKEY`, `INPUT`, and `KEY_HELD` read the ZX81 keyboard
matrix. Letters, digits, Space, Enter, and the shifted punctuation available
on the stock keyboard are supported. Joysticks and keypads are not available.

## Graphics

`DISPLAY CELL` selects the 32x24 character display. The ZX81 does not provide
a bitmap display mode. `PLOT`, `UNPLOT`, `POINT`, lines, boxes, and circles
use the ZX81 2x2 block characters as a 64x44 plotting surface.

The display is monochrome. A color passed to `PLOT` is ignored with a compiler
warning. High resolution, multicolor, sprites, tiles, and image loading are
not available.

## Frames and ticks

`FRAME_WAIT` runs one complete ROM display cycle and advances `FRAME_COUNTER`.
`TICKS` counts calls to `FRAME_WAIT`; it is not a free running clock.
`TICKS_HZ` is 50 on `zx81.orig` and 60 on `zx81.timex_sinclair`.

## ZX81 BASIC dialect

Use `@OPTION DIALECT zx81_basic` for line numbered ZX81 BASIC source. The
dialect supports common listing forms plus `FAST`, `SLOW`, `SCROLL`, `PAUSE`,
`PLOT`, `UNPLOT`, `RAND`, and `RANDOMIZE`.

The dialect uses integer values. `SIN`, `TAN`, `ASN`, `ACS`, `ATN`, and `LN`
return zero; `COS` and `EXP` return one.

## Legacy BASIC files

Legacy tokenized ZX81 and Timex Sinclair 1000 `.p` files can be converted to
editable `zx81_basic` text:

```bash
crustybasic detokenize PROGRAM.p -o PROGRAM.bas
```

The decoder reads the BASIC area and ignores saved display and variable data.
It recognizes the format automatically. Numeric binary copies are removed;
the original number text is retained. Graphics, inverse characters, and raw
bytes in strings or `REM` lines are written as numeric brace escapes such as
`{$81}`.

This supports `.p` program images only. Filename-prefixed `.p81` files, tape
audio, and snapshots are not accepted.
