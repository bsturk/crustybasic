# crustyBASIC on ZX81 and Timex Sinclair 1000

Use `@OPTION TARGET zx81` for the PAL ZX81 profile. Use
`@OPTION SYSTEM zx81.timex_sinclair` for the NTSC Timex Sinclair 1000.

Both systems build a `.p` program for a machine with 16K RAM. Programs
start automatically when loaded unless autorun is disabled.
Portable runtime calls are documented in [`../API.md`](../API.md).

## Systems

| System | Video | Output |
| --- | --- | --- |
| `zx81.orig` | PAL, 50 Hz | `.p` |
| `zx81.timex_sinclair` | NTSC, 60 Hz | `.p` |

## Basics

| Item | Value |
| --- | --- |
| CPU | Zilog Z80 |
| Required RAM | 16K |
| Text | 32x24 |
| Block graphics | 64x44 |
| Code start | `$43AB`, or `$4082` with REM storage |
| Program RAM top | `$8000` |
| `REAL` | Sinclair 5 byte format using the ROM calculator |
| Sound | Not available on a stock machine |

Build a program with a `vasmz80_oldstyle` executable available through the
normal assembler search path:

```bash
crustybasic build hello.cbs -o hello.p
```

## Program storage and autorun

| Option | Default | Effect |
| --- | --- | --- |
| `STARTUP` | `zx81_p` | Use `zx81_p_rem` for machine code in line 1 after `REM`, or `zx81_p` for the saved variable layout. |
| `ZX81_AUTORUN` | `TRUE` | `FALSE` loads the program without running it. |

```basic
@OPTION STARTUP zx81_p_rem
@OPTION ZX81_AUTORUN FALSE
```

The same settings are available on the command line:

```bash
crustybasic build hello.cbs --set startup=zx81_p_rem --set zx81-autorun=false -o hello.p
```

With REM storage, enter `RUN` or `RAND USR 16514` after loading. With the
default storage, enter `RAND USR 17323`; `RUN` clears the saved variable
containing the code. Keep line 1 intact when using REM storage.

## Text and cells

The `.p` wrapper creates a full 32x24 display file, and `TEXT_HEIGHT` exposes
all 24 rows. The ROM may use rows 22 and 23 for input and reports, so programs
that need those displays can reserve the rows themselves. `CLS` clears all 24
rows.

Text is converted to ZX81 display codes as it is printed. `#` prints as a
solid block and unsupported characters are shown as `?`. Brace escapes such as
`{$81}` place the block and inverse glyphs directly. The same escapes work in
pure crustyBASIC and the `zx81_basic` dialect. Printing past the final row
stays on that row.

With `zx81_basic`, `CHR$` and `CODE` use native character codes. `PRINT`
expands keyword characters in strings.

Pure crustyBASIC and the `zx81_basic` dialect both support `SCROLL`. It moves
the display up one row, clears the final row, and puts the `PRINT` position at
the beginning of that row. Scrolling is explicit rather than automatic.

## Input

`KEY`, `INKEY`, `RAWKEY`, `INPUT`, and `KEY_HELD` read the ZX81 keyboard
matrix. Letters, digits, Space, Enter, and the shifted punctuation available
on the stock keyboard are supported. SHIFT+0 (RUBOUT) reads as `KEY_DELETE`
and erases the last character in `INPUT`. Dialect `INPUT` shows the display
while reading and restores FAST mode afterward. Joysticks and keypads are not
available.

In `zx81_basic`, numeric `INPUT` and `VAL` evaluate expressions using the
program's variables, including arrays.

`CLEAR` resets variables and releases array storage. `RUN` clears variables
before starting at the requested line. Both preserve GOSUB return addresses.

## Tape

In `zx81_basic`, `SAVE` records the compiled program and its variables,
including arrays and strings. Loading that recording resumes after `SAVE`.
`LOAD` replaces the running program with a recording; `LOAD ""` accepts the
first recording found. Names can be string expressions. SPACE cancels a tape
operation.

`ZX81_TAPE_SAVE` and `ZX81_TAPE_LOAD` provide the same operations outside the
dialect. Both accept a filename string and use the cassette sockets.

## Printer

The optional ZX Printer supports `LPRINT` and `COPY` in `zx81_basic`.
`LPRINT` accepts expressions, separators, `AT`, and `TAB`. `COPY` prints
the upper 22 screen rows.

`ZX81_PRINTER_BEGIN` and `ZX81_PRINTER_END` send `PRINT` output to the
printer and restore the screen position. `ZX81_PRINTER_WRITE` sends a
native character code, `ZX81_PRINTER_POSITION` sets the column, and
`ZX81_PRINTER_FLUSH` prints the pending line. `ZX81_PRINTER_COPY` copies
the upper 22 screen rows.

## Graphics

`DISPLAY CELL` selects the 32x24 character display. The ZX81 does not provide
a bitmap display mode. `PLOT`, `UNPLOT`, `POINT`, lines, boxes, and circles
use the ZX81 2x2 block characters as a 64x44 plotting surface.

The display is monochrome. A color passed to `PLOT` is ignored with a compiler
warning. Tiles use the character cell surface.

## Frames and ticks

`FRAME_WAIT` runs one complete ROM display cycle and advances `FRAME_COUNTER`.
`TICKS` counts ROM display frames, including time spent computing between
waits. The clock advances in SLOW mode and pauses in FAST mode.
`TICKS_HZ` is 50 on `zx81.orig` and 60 on `zx81.timex_sinclair`.
`DISPLAY_HIDE` selects FAST mode and blanks the display; `DISPLAY_SHOW`
selects SLOW mode and restores it.

## ZX81 BASIC dialect

Use `@OPTION DIALECT zx81_basic` for line numbered ZX81 BASIC source. The
dialect supports common listing forms plus `FAST`, `SLOW`, `SCROLL`, `PAUSE`,
`PLOT`, `UNPLOT`, `RAND`, and `RANDOMIZE`.

The dialect supports fractional values and math functions through the
Sinclair ROM calculator.

`DIM` evaluates its bounds when it runs. Repeating `DIM` resizes the array
and resets numbers to zero or characters to spaces. String widths stay
fixed until the next `DIM`.

## Legacy BASIC files

Legacy tokenized ZX81 and Timex Sinclair 1000 `.p` files can be converted to
editable `zx81_basic` text:

```bash
crustybasic detokenize PROGRAM.p -o PROGRAM.bas
```

The decoder reads the BASIC area and saved variable values, including array
contents. These values initialize the compiled program. It recognizes the
format automatically. Numeric binary copies are removed;
the original number text is retained. Graphics, inverse characters, and raw
bytes in strings or `REM` lines are written as numeric brace escapes such as
`{$81}`.

This supports `.p` program images only. Filename-prefixed `.p81` files, tape
audio, and snapshots are not accepted.
